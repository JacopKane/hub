hub stopped this git command, because a variable or a substitution fills in git's action or an option before it, as in git $ACTION origin main. From that, the PR test gate can not see whether git pushes, so it stops every such command, even a safe one such as git $OPTS log. Write the action and the options before it in full, as in git push origin main or git --no-pager log, and send the command again.
