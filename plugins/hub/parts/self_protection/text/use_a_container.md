hub's switch step can not make changes on a line that does more than read HOME, an XDG folder or CLAUDE_CONFIG_DIR. The same goes for a line that runs eval, source or the . command. On this machine the step's background jobs belong to your whole account, so a test home would still change your real jobs. Run the step on a line of its own, by its full path if it comes from a virtual environment. To try hub with a test home, use a Docker or Podman container with no mounts.
