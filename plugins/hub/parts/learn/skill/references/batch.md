# Batch

When several learnings are collected at once, for example from threads, past chats or a review, write nothing first. Ask them with the question tool, one learning per question, with its exact lines, the target file and what it costs, your pick first. Apply each answered round, then ask the next. Each write still goes through the zone check in step 5 of the skill.

Bring only broad changes in behavior, not narrow exceptions. Think of integration tests, not unit tests. Merge cases that share a cause into one rule, settle tool details yourself or drop them, and drop one-offs.
