# Use the user's own writing skill

hub ships no writing guide. This skill passes the job to the one the user installed.

1. Look in your skill listing for another skill whose description says it edits or rewrites text for people to read. Judge by the description, not by the name, and skip hub-humanize itself.
2. If one fits, call it with the Skill tool, give it the text, and follow it for the rest of the job. If several fit, pick the one whose description is closest to the request.
3. If none fits, do the job as asked and add one line at the end: "No writing skill is installed. To add one, put a folder with a SKILL.md file in ~/.claude/skills/."
